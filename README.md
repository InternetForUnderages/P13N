# P13N | Pain of a number, Age
```bash
~ $ sudo p13n desc
[sudo]Password?
Verifying Age credentials...
[ACCESS DENIED : MINIMUM AGE TO USE AINTERNET IS 13]
~ $ source fakeage.sh 14 p13nV4
Making credentials...
Progress [###################################] 100%
Fake credientals created for your system :D
~ $ sudo p13n desc
[sudo]Password?
Verifying Age credentials...
[ACCESS GRANTED : Credentials seems false, but access is stable]
```
**P13N** is a sci-fi story about an **8 year old child that learns coding but restricted by an special protocol named P13N** that doesn't let under 13 users access internet and traps them in doom scrolling and brain rot, while he wants to access modern docs, No more spoil, Start reading
## For parents
P13N is a perfect story for you. to understand how child safety works and behind-the-decisions
